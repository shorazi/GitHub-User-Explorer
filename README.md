# GitHub User Explorer

```bash
npm install

```

## staleTime и gcTime

```ts
const queryClient = new QueryClient({
	defaultOptions: {
		queries: {
			staleTime: 5 * 60 * 1000,
			gcTime: 10 * 60 * 1000,
		},
	},
})
```

**staleTime: 5 минут**  
Результаты поиска GitHub не меняются секунда в секунду.
5 минут - разумный период в течение которого можно считать
данные свежими и не делать лишних сетевых запросов при
повторном посещении страницы или фокусе вкладки.

**gcTime: 10 минут**  
Кэш живёт 10 минут после размонтирования компонента.
При возврате назад на SearchPage данные берутся из кэша
мгновенно - нет повторного запроса, нет скелетона.

**gcTime > staleTime намеренно:** данные могут быть stale
(требуют фоновой ревалидации в фоне), но они есть в кэше
и показываются сразу.
